## نظرة عامة

«مُتَابِع» تطبيق ويب تقدمي (PWA) يساعد المسلم على تنظيم وِرده اليومي ومتابعته بدقة: تسجيل الصلوات (جماعة / منفردًا / فائتة)، قراءة القرآن وحفظه، الأذكار والتسبيح، قراءة الأحاديث والكتب، وإدارة المهام، مع إحصائيات وأوسمة ونقاط تحفّز على الاستمرار.

يعمل التطبيق على الهاتف والحاسوب، ويحفظ التقدّم محليًا ثم يزامنه تلقائيًا مع السحابة عند عودة الاتصال.

## المزايا

### العبادات والورد اليومي
- **الورد اليومي**: أنشطة قابلة للتخصيص (حفظ، تلاوة، سماع، أذكار، صيام…) مع هدف يومي شخصي وتأكيدات تشجيعية.
- **متابعة الصلوات الخمس**: جماعة / منفردًا / فائتة مع ملاحظة السبب، وتسجيل سريع من إشعار دخول الوقت.
- **مواقيت الصلاة**: حساب فلكي حسب الموقع بمكتبة `adhan`، مع Aladhan API كمصدر أساسي وحساب محلي احتياطي، ودعم عدة طرق حساب.
- **تقويم العبادات**: عرض شهري للصلوات المكتملة وأيام الصيام.

### القرآن الكريم
- **قارئ المصحف**: نص عثماني (رواية حفص) عبر Quran Foundation API، مع عرض النص أو صورة صفحة المصحف.
- **التفسير الميسر**، وبحث في السور والآيات، وعلامة مرجعية، واستعادة آخر موضع قراءة.
- **التلاوة الصوتية** بأصوات الحصري والعفاسي والمنشاوي: سماع آية، أو قراءة متواصلة من آية، أو السورة كاملة.
- **راحة العين**: أنماط إضاءة (سيبيا / ليلي / فاتح) وعدة خطوط عثمانية وأحجام قابلة للضبط.
- **الحفظ والختمة**: تسجيل الحفظ والمراجعة، ومتابعة الختمة (604 صفحة) والجزء والحزب والربع.

### الأذكار والعلم
- **موسوعة الأذكار** بتصنيفاتها (الصباح، المساء، بعد الصلاة، النوم، الكرب، الرقية، السفر، الطعام…) مع عدّاد تفاعلي وتخريج لكل ذكر.
- **المسبحة الرقمية** مع أهداف الجولات وحفظ الإجمالي اليومي.
- **دليل الصلوات**: الاستخارة، التوبة، الضحى، قيام الليل، الوتر، مع بيان الأدلة ومواضع الخلاف.
- **الأحاديث**: الأربعون النووية (مشكولة مع الفوائد)، وصحيحا البخاري ومسلم بتحميل عند الطلب.
- **المكتبة الإسلامية**: قارئ داخلي لنصوص مرخّصة (السيرة الحلبية، جلاء الأفهام) وروابط لمصادر أخرى.

### التقدم والتحفيز
- سلسلة الأيام المتواصلة، خريطة الالتزام (Heatmap)، رسم أسبوعي، أوسمة، ونقاط ورتب إيمانية.
- **سجل الإنجازات** بتصفية حسب النشاط والفترة، وتصدير البيانات الشخصية بصيغة CSV.
- **قائمة المهام**: أولويات وتصنيفات ومهام فرعية وتواريخ استحقاق، بمزامنة سحابية.

### الإدارة
- **لوحة المشرف**: متابعة المستخدمين الذين وافقوا صراحةً على المتابعة، وعرض ما أنجزوه وما فاتهم.
- إدارة الأنشطة (ترتيب، ألوان، أيقونات، فيديوهات وقوائم تشغيل)، والعبارات التشجيعية.
- مراسلة المستخدمين برسائل تشجيع (مع ردّ واحد لكل رسالة)، وتصدير تقارير CSV.

### التجربة العامة
- واجهة عربية RTL بالكامل، ووضع فاتح/داكن.
- تثبيت كتطبيق (PWA) مع إشعار تحديث تلقائي.
- إشعارات محلية وإشعارات سحابية (FCM) لأوقات الصلاة.

> التنقل داخل التطبيق يعتمد على الـ hash (مثل `/#today` و`/#hadith`)، والمسارات معرّفة في `public/manus-routes.json`.

## البدء السريع

### المتطلبات

- Node.js **22** أو أحدث (كما في CI)
- حساب ومشروع Firebase مفعّل فيه **Authentication** و**Firestore** (و**Cloud Messaging** للإشعارات)

### التثبيت والتشغيل

```bash
git clone <repository-url>
cd mutabi

npm ci
cp .env.example .env.local   # ثم عدّل القيم المطلوبة
npm run dev
```

يعمل خادم التطوير على `http://localhost:3000`.

## متغيرات البيئة والإعداد

| المتغير / الملف | الوصف |
| --- | --- |
| `firebase-applet-config.json` | إعدادات مشروع Firebase للواجهة (إعدادات عميل عامة وليست أسرارًا) |
| `VITE_FIREBASE_VAPID_KEY` | مفتاح Web Push (VAPID) لتفعيل إشعارات FCM؛ بدونه يعمل التطبيق بالإشعارات المحلية فقط |
| `serviceAccountKey.json` أو `GOOGLE_APPLICATION_CREDENTIALS` | مفتاح خدمة لتشغيل `scripts/make-admin.mjs` فقط |

> **تنبيه أمني:** لا ترفع `serviceAccountKey*.json` ولا ملفات `.env*` إلى المستودع (مستثناة في `.gitignore`)، ولا تضع مفاتيح الخادم في كود الواجهة.

### تعيين مشرف

```bash
node scripts/make-admin.mjs <USER_UID>
```

إن لم يوجد مفتاح خدمة، يطبع السكربت خطوات الإضافة اليدوية: إنشاء مستند في مجموعة `admins` بمعرّف المستخدم وحقل `createdAt`.

كما يُعامَل البريد الجذري المعرّف في `firestore.rules` و`AuthContext.jsx` كمشرف عند توثيقه. غيّره إلى بريدك عند نشر نسختك الخاصة.

## Firebase

### المجموعات الرئيسية في Firestore

| المسار | المحتوى |
| --- | --- |
| `users/{uid}` | الملف الشخصي والتفضيلات وإعدادات التنبيهات |
| `users/{uid}/adhkarProgress` | عدّادات الأذكار اليومية |
| `users/{uid}/hadithProgress` | الأحاديث المقروءة والمفضلة |
| `users/{uid}/todos` | قائمة المهام الشخصية |
| `users/{uid}/fcmTokens` | رموز الإشعارات للأجهزة |
| `logs/{uid_activity_date}` | سجل الإنجاز اليومي |
| `activities/{id}` و`/items` | تعريف الأنشطة ومقاطعها |
| `itemProgress/{id}` | تقدّم مشاهدة المقاطع |
| `notes/{id}` | رسائل المشرف وردود المستخدمين |
| `encouragements/{id}` | العبارات التشجيعية |
| `admins/{uid}` | علامة صلاحية المشرف |

### النشر

```bash
npm run build
firebase deploy --only firestore:rules,firestore:indexes
firebase deploy --only hosting
firebase deploy --only functions   # يتطلب خطة Blaze
```

يخدم Hosting مجلد `dist` مع إعادة توجيه كل المسارات إلى `index.html`، ويمنع التخزين المؤقت لـ `index.html` و`sw.js` لضمان وصول التحديثات.

## الإشعارات (FCM)

- تُجدول الدالة `dispatchPrayerNotifications` للتنفيذ كل دقيقة، فتقرأ المستخدمين المفعّلين للتنبيهات، وتحسب مواقيتهم بحسب موقعهم ومنطقتهم الزمنية وطريقة الحساب، ثم ترسل الإشعار عند دخول الوقت.
- يمنع التكرار سجلّ `notificationLog` بمفتاح `uid + prayer + localDate`، وتُحذف الرموز غير الصالحة تلقائيًا.
- طلب إذن الإشعارات يتم بعد تفاعل المستخدم، ويُسجَّل رمز الجهاز تحت `users/{uid}/fcmTokens`.
- تفاصيل الخطة في `public/docs/FCM-PLAN.md`.

> **ملاحظة صيانة:** ملف `shared/prayer-methods.cjs` موجود بنسختين (للواجهة وللدوال). عند تعديله حدّث النسختين معًا.

> الإشعارات تعتمد على إذن النظام واتصال الجهاز وسياسات توفير الطاقة؛ لا يمكن ضمان وصولها في كل الظروف.

## العمل دون اتصال

يوفّر التطبيق ثلاث حزم تنزيل اختيارية من نافذة «العمل بدون إنترنت»:

| الحزمة | المحتوى |
| --- | --- |
| **الأساسي** | نص القرآن وبيانات الصفحات والتفسير والأذكار |
| **مكتبة القراءة** | الأساسي + كتب الحديث كاملة + صور صفحات المصحف |
| **الكاملة** | كل ما سبق + تلاوات السور (قد تتجاوز 1 جيجابايت) |

- التنزيل يبدأ بعد اختيار المستخدم، ويُستكمل من حيث توقف.
- تُحفظ عمليات الكتابة (الإنجازات، المهام، الأذكار…) في **طابور محلي** وتُرفع تلقائيًا عند عودة الاتصال مع إعادة محاولة تصاعدية.
- يمكن حذف المحتوى المحفوظ دون المساس بالحساب أو التقدّم.

## الأمان والخصوصية

- قواعد Firestore تمنع أي مستخدم من قراءة بيانات غيره أو تعديلها، وتمنع المستخدم من تغيير حالة تعطيل حسابه.
- **لا يرى المشرف بيانات أي مستخدم إلا بعد موافقته الصريحة** (`adminMonitoringConsent`)، ويمكن للمستخدم سحبها في أي وقت.
- رموز FCM مقروءة لصاحبها فقط، وتستخدمها الدالة السحابية بصلاحيات الخادم.
- يوثّق `security_spec.md` قيود البيانات وسيناريوهات الهجوم المحظورة.

## المصادر والتراخيص

- **القرآن والتفسير**: [Quran Foundation API](https://api-docs.quran.foundation)، والتفسير الميسر (مجمع الملك فهد) عبر QuranEnc وAl-Quran Cloud.
- **الأحاديث**: [fawazahmed0/hadith-api](https://github.com/fawazahmed0/hadith-api) لصحيحَي البخاري ومسلم. الفهارس تحصي سجلات النسخة المستخدمة وقد تختلف عن عدّ الأحاديث المتفردة.
- **الأذكار والصلوات**: نصوص منتقاة مع تخريجها وروابط مراجعها، وتوضّح `docs/adhkar-sources.md` ما ثبت وما اختُلف فيه.
- **الكتب المضمنة**: من ويكي مصدر العربية بترخيص [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)، والتفاصيل في `public/books/ATTRIBUTION.md`. عند إعادة استخدامها حافظ على النسبة والمشاركة بالمثل.
- **الخط**: Amiri بترخيص SIL OFL 1.1 (`public/fonts/OFL-Amiri.txt`).
- **مواقيت الصلاة**: [Aladhan API](https://aladhan.com/prayer-times-api) ومكتبة [adhan](https://github.com/batoulapps/adhan-js).

> هذا المشروع أداة تعليمية للمتابعة، وليس فتوى شرعية. في مسائل الخلاف الفقهي يُرجع إلى أهل العلم الموثوقين.
